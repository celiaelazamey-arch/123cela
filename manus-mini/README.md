# Manus Mini

نسخة ويب لمساعد مشاريع عربي. تشمل محادثة ببث حي، تبديل مزود النموذج من إعداد الخادم، وبحثًا عامًا يعرض خطة ومصادر قبل القراءة، وقراءة PDF وملفات نصية، وذاكرة وسجل مهام، وتصدير الردود. تحفظ مساحة العمل محليًا، ويمكن تفعيل مزامنتها اختياريًا عبر Supabase.

## التشغيل

المتطلبات: Node.js 22.13 أو أحدث وnpm.

1. فك ضغط المشروع وافتح مجلده في Terminal.
2. شغّل `npm install`.
3. انسخ `.env.example` إلى `.env.local`.
4. ضع مفتاحًا واحدًا على الأقل بحسب المزود الذي اخترته.
5. شغّل `npm run dev` وافتح `http://localhost:3000`.

إعداد Gemini الافتراضي:

```env
AI_PROVIDER=gemini
GEMINI_API_KEY=مفتاحك_من_Google_AI_Studio
GEMINI_MODEL=gemini-3.8-flash
```

النموذج يستخدم Gemini Interactions API مع بث فعلي. حصة الاستخدام المجانية محدودة، وقد تختلف حسب الحساب والنموذج. لا تستخدم الخطة المجانية للبيانات الحساسة.

## مزودات بديلة

Hugging Face:

```env
AI_PROVIDER=huggingface
HF_TOKEN=رمز_Hugging_Face
HF_MODEL=اسم_النموذج_المتاح_في_Inference_Providers
HF_BASE_URL=https://router.huggingface.co/v1/chat/completions
```

NVIDIA NIM:

```env
AI_PROVIDER=nvidia
NVIDIA_API_KEY=مفتاح_NVIDIA
NVIDIA_MODEL=meta/llama-3.3-70b-instruct
NVIDIA_BASE_URL=https://integrate.api.nvidia.com/v1/chat/completions
```

Groq Free:

```env
AI_PROVIDER=groq
GROQ_API_KEY=مفتاح_Groq
```

يستخدم هذا الوضع النموذج `openai/gpt-oss-20b` الثابت، المدرج ضمن حدود Free الحالية لدى Groq، ولا ينتقل تلقائيًا إلى مزود آخر عند بلوغ الحصة. تأكد أن حساب Groq لديك على Free؛ لا تُضف وسيلة دفع أو ترقِ الحساب إذا كان المطلوب عدم إنفاق المال. حدود الحصة قابلة للتغيير من المزود.

تغيير `AI_PROVIDER` أو `*_MODEL` يتطلب إعادة تشغيل التطبيق. لا تضف مفاتيح Grok أو Kimi إلى إعداد التطبيق؛ هذه الواجهة لا تستخدمها. مفاتيح Tavily وngrok ليست مطلوبة لمسار البحث الحالي.

## الأمان والبيانات

- المفاتيح تقرأ على الخادم فقط، ولا تعرضها واجهة التطبيق.
- لا ترفع `.env.local` أو أي مفتاح إلى GitHub.
- قبل نشر التطبيق على الإنترنت، عيّن `APP_ACCESS_PASSWORD` و`SESSION_SECRET` في إعدادات الاستضافة.
- الحماية بكلمة مرور واحدة مناسبة لأداة شخصية فقط، وليست نظام حسابات متعدد المستخدمين.
- افتراضيًا، تحفظ المشاريع والمحادثات والذاكرة وسجل المهام في `localStorage` بالمتصفح الحالي.
- لتفعيل الحفظ السحابي، أنشئ مشروع Supabase، نفّذ `supabase/schema.sql` في SQL Editor، ثم عيّن `SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` في `.env.local` أو إعدادات الاستضافة. أعد تشغيل التطبيق بعد التعديل.
- مفتاح Supabase من نوع `service_role` يبقى على الخادم فقط، ولا تضفه إلى متغير يبدأ بـ`NEXT_PUBLIC_` أو ترفعه إلى GitHub. تخزن هذه النسخة مساحة عمل واحدة مشتركة لكل من يدخل بكلمة المرور، وليست حسابات منفصلة.
- عند تفعيل Supabase، تُحمّل النسخة السحابية عند فتح التطبيق وتُحفظ التغييرات تلقائيًا بعد توقفها القصير؛ يحتفظ المتصفح أيضًا بنسخة محلية. إذا لم يتصل التطبيق بقاعدة البيانات، تبقى النسخة المحلية متاحة ولا يكتب التطبيق فوق السحابة قبل نجاح القراءة.
- PDF.js يستخرج النص داخل المتصفح. عند إرسال الرسالة، يرسل نص الملف إلى مزود الذكاء الاصطناعي.
- البحث يستخدم HTML العام من DuckDuckGo وقد يتوقف أو يتغير. يعرض التطبيق الخطة وأول 3 مصادر مرشحة وينتظر موافقتك قبل فتحها. الخطة صالحة 10 دقائق.
- قراءة الصفحات تقتصر على HTTPS العام، وترفض عناوين IP الخاصة أو المحجوزة، وتثبت عنوان DNS أثناء الاتصال، ولا تتبع التحويلات. يقرأ التطبيق حتى 3 صفحات HTML، بحد أقصى 1 ميغابايت لكل صفحة، ويرسل مقتطفات حتى 6000 حرف لكل مصدر إلى مزود الذكاء الاصطناعي. محتوى الصفحات غير موثوق ولا تُتبع التعليمات الواردة فيه.
- البحث والقراءة لا ينفذان تسجيل دخول أو نقرات أو إرسالًا أو شراءً أو نشرًا أو أي تعديل خارجي. مخطط Python في `../computer_use/` وعامل Cloudflare في `../ccelia2027/` لا يزالان وحدتين منفصلتين وغير موصولين بهذه الواجهة.
- حد الطلبات الحالي مدمج في ذاكرة خادم Next.js؛ أضف مخزنًا مشتركًا للمعدل ومصادقة فعلية قبل فتح استخدام عام واسع.
- تُحدد محاولات الدخول بخمس محاولات في الدقيقة لكل عنوان موثوق يمرره مزود الاستضافة (أو حد مشترك عند غيابه). حد المصادقة مدمج في ذاكرة العملية ولا يغني عن بوابة حماية أو محدد موزع في نشر متعدد النسخ.
- لا ينفذ التطبيق أوامر النظام أو حذف الملفات أو إرسال البريد أو الشراء أو النشر. الطلبات الحساسة تتحول إلى تخطيط فقط.

## النشر على Vercel

ارفع المجلد إلى GitHub ثم أنشئ مشروعًا على Vercel من المستودع. أضف متغيرات البيئة نفسها من إعدادات المشروع، مع كلمة مرور وصول و`SESSION_SECRET` عشوائي طويل. أضف `SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` فقط إذا أعددت التخزين السحابي. ثم أعد النشر. لا تستخدم `NEXT_PUBLIC_` للمفاتيح السرية.

هذه نسخة MVP عاملة للاستخدام الشخصي والتجربة. قاعدة البيانات متعددة المستخدمين، تخزين الملفات السحابي، مهام الخلفية، المتصفح الآلي، وتشغيل الأوامر المعزول غير موصلة بعد.
