# 123cela

مستودع متعدد الوحدات لمساعد CELA. واجهة `manus-mini` تجمع المحادثة مع بحث الويب للقراءة فقط بخطة وموافقة قبل فتح المصادر. مخطط Python المحلي وعامل Cloudflare يبقيان وحدتين منفصلتين ولا يتصلان بالواجهة تلقائيًا.

## الوحدات

- الجذر: محرك تخطيط Python محلي يعتمد Ollama، ويُخرج خططًا فقط (`dry_run=true` و`execution_enabled=false`). لا ينفذ النقرات أو أوامر النظام.
- `ccelia2027/`: عامل ويب للبحث والقراءة العامة المحدودة. لا يسجل الدخول للمواقع ولا يرسل أو يشتري أو يغيّر بيانات.
- `manus-mini/`: واجهة مساعد ويب للمحادثة والملفات النصية وPDF، وبحث عام يعرض الخطة والمصادر قبل القراءة، مع إعداد مزود الذكاء الاصطناعي على الخادم.

تكامل البحث في Manus Mini يقرأ حتى 3 صفحات عامة عبر HTTPS بعد موافقة المستخدم. يتحقق من عناوين DNS، يرفض الوجهات الخاصة والتحويلات، ثم يرسل مقتطفات الصفحات إلى مزود النموذج المحدد. لا ينفذ نقرات أو تسجيل دخول أو إرسالًا أو شراءً أو تغييرًا للبيانات. عامل `ccelia2027/` ومخطط `computer_use/` لا يزالان يعملان مستقلين؛ النشر/الربط بينهما وبين الواجهة يحتاج إعدادًا منفصلًا.

## الفحوص

فحص GitHub Actions يشغّل اختبارات Python وفحوص العامل والواجهة عند الدفع أو فتح طلب دمج. يتطلب التشغيل المحلي Python 3.11+ وNode.js 22.13+ وnpm.

## النشر

نشر `ccelia2027` يدوي فقط من GitHub Actions. يحتاج أسرار Cloudflare وإعدادات حماية التطبيق، ويتوقف ما لم يؤكد المشغّل أن الحساب على الخطة المجانية دون فوترة. لا يُنشر أي شيء تلقائيًا عند الدفع.

لا ترفع ملفات `.env` أو مفاتيح API أو كلمات المرور. استخدم ملفات `.env.example` و`.dev.vars.example` كنماذج إعداد فقط.
